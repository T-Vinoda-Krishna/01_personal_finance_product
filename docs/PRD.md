# Product Requirements Document

## 1. Objective
Help users understand spending and make one practical financial decision per week.

## 2. User stories
- As a user, I want my transactions categorized automatically so I can see spending by category.
- As a user, I want to set a monthly budget so I know when I am overspending.
- As a user, I want unusual-spending alerts so I can catch unexpected expenses.
- As a user, I want a savings goal so I can see whether I am on track.

## 3. Functional requirements
1. CSV upload
2. Transaction table with search/filter
3. Category assignment
4. Monthly budget controls
5. Budget utilization chart
6. Unusual-transaction alert
7. Savings-goal tracker
8. Export cleaned data

## 4. Non-functional requirements
- No financial advice
- Transparent calculations
- Responsive UI
- No sensitive data stored in the demo

## 5. Acceptance criteria
- User can upload a CSV with date, description, amount, category.
- Dashboard calculates monthly spend correctly.
- Budget utilization updates immediately after edits.
- Anomaly flagging is explainable.
